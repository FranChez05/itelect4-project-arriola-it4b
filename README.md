# Badminton Court Booking System

[![CI](https://github.com/FranChez05/itelect4-project-arriola-it4b/actions/workflows/ci.yml/badge.svg?branch=GT6-Tests-Arriola)](https://github.com/FranChez05/itelect4-project-arriola-it4b/actions/workflows/ci.yml)

This project models a simple badminton court booking system for admins and players. It uses TypeScript interfaces, enums, generics, and utility types to define core entities such as users, courts, bookings, and API responses.

## Types defined
- User
- Court
- Booking
- ApiResponse<T>
- UserUpdate
- PublicUser
- UserRole (type union)
- BookingStatus (enum)

## Install dependencies
```bash
npm install
```

## Run the app
Use either of the following commands:

```bash
npm start
```
or
```bash
npx ts-node src/index.ts
```

## Type check
```bash
npm run check
```

Make sure Node.js and npm are installed before running the project.
